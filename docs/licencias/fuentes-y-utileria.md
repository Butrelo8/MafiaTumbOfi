# Fonts and props made for the truck scenes

- **Grenze Gotisch ExtraBold** (`blender/fuentes/GrenzeGotisch-800.ttf`), the MT hood emblem. SIL Open Font License 1.1,
  copyright 2020 The Grenze Gotisch Project Authors (github.com/Omnibus-Type/Grenze-Gotisch); full text in
  `blender/fuentes/GrenzeGotisch-OFL.txt`. Converted to TTF from the @fontsource 5.3.0 woff2 (latin subset, weight 800) with
  fontTools; the OFL allows that conversion and bundling with the project.
- **Strawberry charm** (`blender/props/fresa.glb`): modelled from scratch by `blender/fresa_charm.py`, no third-party mesh or
  texture. If a friend's model replaces it, record its licence here.
- The lamp in the roof spoiler's pockets and the emblem's plinth are procedural (`blender/props_placement.py`). The G63 6×6
  model they sit on is CC-BY-4.0 (DJS on Sketchfab; see the main checkout's `blender/assets/camion/g63-6x6/modelo/license.txt`).
