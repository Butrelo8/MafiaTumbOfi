## gotchas (for visual-lab)
- Camera route orbiting a box with one end inside it -> the "lift over the roof" divides by sin(pi t) near the end: 13.5-14.8 m jumps; give in-box stops a straight exit leg first.
- Cameras on the cab roof looking down into the cab were all blocked by the roof edge (0.3-0.46 m) -> a grid search (clearance + sight line) found free spots only at window height just outside the side glass.
- Point lights placed "over each seat" before the cast was swapped ended up inside the new heads -> after any cast swap, test each lamp with closest_point_on_mesh (inside = behind the face normal).
- A sight-line check that skips every cast hit can't prove a member shot is clear -> skip only the target member's own meshes.
- The Blender hook refuses GPU=0 on a script that contains render calls even in a no-render mode -> add ANIM_SIN_RENDER=1.
- render.sh's gpu-busy wait also blocks the script's no-render modes -> run those directly with GPU=0 ANIM_SIN_RENDER=1.
- esperar.sh log matched the previous run's "listo" line in a reused log -> wait on the output file, or move the old log first.
