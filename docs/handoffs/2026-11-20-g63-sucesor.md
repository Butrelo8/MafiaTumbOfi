## gotchas
- gotchas: glTF import in Blender shows 3 of 4 baked cast rigs in rest pose -> the importer puts every clip on a muted NLA track and activates only the first; set `rig.animation_data.action` from the strip (or check the GLB by FK) before blaming the export.
- gotchas: GLTFLoader renames same-named bones of several rigs `Hips_1`, `Hips_2` -> strip `_\d+$` before matching them by name.
- gotchas: TTFF stayed at the file's bandwidth floor although the file shrank -> the fetches started only after WebGLRenderer + PMREM were built (~0.5 s main thread at 390) and the Draco wasm only after the glb was whole; start the downloads first and `DRACOLoader.preload()`.
- gotchas: `fetch(url, {priority: 'high'})` did not move a glb ahead of a media element on Cloudflare -> no gain, drop it.
- gotchas: Draco 14/10 -> 12/8 bits on a 1.9 MB geometry file cut 16 % with edge-only pixel diffs (mean <= 0.5/255 at 1440) -> a lever for TTFF when triangles must stay.
- gotchas: `medir-vivo.mjs` takes ~10 min per run; `SOLO_TTFF=1` (in WSLENV) runs only the 4G TTFF block (~25 s).
- gotchas: a worktree can lose its `.git` and tracked files while a session runs (shown "prunable") -> `git worktree prune` + `git worktree add <new path> <branch>`; git-ignored files (`public/vivo/*.glb`, `draco/`) are gone with it.
