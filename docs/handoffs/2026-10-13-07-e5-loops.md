## Avisos de esta sesión (los generales ya van como `gotchas:` en el informe de middrone)

- Varias sesiones hacen commits en el mismo repo: si aparece `index.lock`, esperar a que se libere (nunca borrarlo) y
  hacer commit sólo de las rutas propias con `git commit -- <rutas>`.
- El hook de Bash bloquea cualquier orden con `numpy`/`cv2` junto a `python3`, aunque sea un `python3 -c` sobre JSON o un
  heredoc que edita un `.py` → `jq` para JSON, Edit para `.py`.
- La reproyección con prueba de profundidad deja bordes falsos en geometría fina (la reja del atrio). Con un centro
  óptico compartido, mejor el recorte afín (`tmp/07/e4/encuadre/medir.py`, `verticales.py`).
- Para clips de Veo, usar nuestro RTX y no el "Upscaled" de Flow (sobreafila y arrastra textura;
  `tmp/07/flow/upscale_job2.md`).
