## gotchas (for visual-lab)
- A three.js cab lit beige with no occlusion -> look at every moving PointLight's position first; an exporter that reads
  `matrix_world` of a light inside an instanced collection gets (0,0,0).
- Diffuse x0 did not darken a surface -> it is specular from a close light, not the environment; hide lights one by one.
- `wslpath -w` on a relative path gives a relative Windows path that Blender resolves against its own cwd (C:\) -> pass absolute paths.
- Blender ortho camera with `to_track_quat("-Z", "Z")` for a side view came out rotated 90° -> use "Y" as the up axis (local Y = image up).
- A script exec'd into montaje's chain shares its globals -> a helper named like the chain's (`choques`) breaks the chain; prefix.
- Saira has no arrow glyphs (↗ renders as a box) -> no arrows in Saira copy, or draw them.
