# Usage

Se instala con el preset `animacion-blender` (`mpaf preset apply animacion-blender --project <repo>`), que
agrega el MCP `blender` al `.mcp.json` del repo (misma config que `MTO/.mcp.json`).

Requiere: Blender en Windows, ffmpeg, cuenta Adobe para Mixamo; para el MCP, `uvx.exe` de Windows y
Blender abierto.

Fuente de verdad: esta skill en MPAF (`skills/blender/`).
